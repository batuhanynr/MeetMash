# M4 network experiments

From the repository root, run `npm run lab:smoke` to cut C’s WSS data link, verify that its management channel still answers, and restore data access. `node scripts/m4/round-smoke.mjs` also sends a signed ACCEPT with an obsolete round ID and checks the coordinator still waits for C’s current vote.

`npm run demo:m4` runs one normal meeting, takes C offline for 30 seconds, drops a recipient ACK, and delivers duplicate confirmations. `npm run bench:network` runs the full predeclared matrix in `scripts/m4/profiles.json`. Each sample has its own meeting ID and agent state. The bench provisions test credentials and deletes its own Docker project and volumes on exit.

Use `-- --jobs=4` to run four isolated topologies at once, or pass `-- --profiles=N0,N2 --count=1` for a smoke run. Jobs share the Docker host CPU. Every raw row identifies the fixture, commit, image ID, worker count and time budget. The runner writes a new directory under `.state/evidence/m4` unless you supply an empty directory with `--out=PATH`. To regenerate the full matrix summary from raw rows, run `node scripts/m4/report.mjs PATH`. An incomplete sample count is reported separately. A failing mandatory profile sets a nonzero exit status.

Each app has its own network namespace. Docker’s internal data bridge carries WSS traffic on port 8787. The hub has a second NIC on a private database bridge. The host uses Docker exec for IPC/management even while WSS is down. Provisioning gives each agent its own bootstrap and pair keys; the hub gets its TLS key and the public bootstrap hashes. No service exposes a host port.

For manual experiments on a running lab project, `npm run lab:apply -- PROJECT N1` and `npm run lab:reset -- PROJECT` install/remove NetEm on each app’s data egress. Obtain PROJECT from `docker compose ls`. Applying N1 adds 150 ms per egress. N2 adds 20 ms jitter and 5% packet loss at every data egress. A relayed request crosses two such egresses. The raw qdisc snapshots include kernel-assigned seeds, observed counters and clean reset state. Lab-only application hooks act on logical frames inside the WSS endpoints; ordinary launches never load them.

Elapsed/recovery times use a single monotonic clock in the controller on A’s node, including when A’s application process restarts. Per-message receipt latency uses one PostgreSQL clock and spans enqueue through recipient ACK, including transit. For N3 the first queued REQUEST to C also records the observed offline wait. NetEm changes the TCP path, where TCP can retransmit lost segments; application retry, durable queue delivery and inbox deduplication are measured separately. These samples emulate packet impairments on a Linux bridge and do not measure a cellular radio channel. Air setup and outstanding verification are described in `infra/air/README.md`.
